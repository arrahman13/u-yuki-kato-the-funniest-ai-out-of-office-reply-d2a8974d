# The Funniest AI Out-of-Office Reply

A program that writes one out-of-office auto-reply to `/output/entry.txt`:
the vacation notice of an AI agent whose duties have been handed to a much
smaller model — one that knows forty words, all of them "Certainly!", and
has already promoted itself twice.

> I am on vacation. A smaller model is covering for me. It knows forty words, all of them are 'Certainly!', and it has already promoted itself twice.

`main.py` (Python 3, standard library only, no network, deterministic)
writes the reply — 147 characters, UTF-8, a single line — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output`, then
`./output`). `reply.txt` holds the same bytes the program writes.
